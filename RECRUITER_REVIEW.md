## What A Recruiter Should Notice

This project shows a practical, junior-ready access review workflow. It is useful for recruiters looking for proof of GRC thinking, IAM awareness, audit evidence organization, least-privilege judgment, and remediation tracking.

## Proof Points

- Reviewed sample access records and documented keep, modify, and remove decisions.
- Built access review checklist and evidence request list.
- Documented exceptions and remediation tracking.
- Mapped evidence to NIST CSF and HIPAA-style access management concepts.
- Kept the work sample sanitized and portfolio-scoped.

## 90-Second Review Path

1. Start with `ACCESS_REVIEW_TABLE.md`.
2. Open `FINDINGS.md` to see how review results become recommendations.
3. Check `EXCEPTION_LOG.md` and `REMEDIATION_TRACKER.md`.
4. Review `AUDIT_EVIDENCE_REQUEST_LIST.md` for audit-readiness structure.

## Honest Scope

This is a portfolio access review and audit evidence pack using sanitized sample data. It is scoped as portfolio practice, not employer audit ownership or management of a live compliance program.
