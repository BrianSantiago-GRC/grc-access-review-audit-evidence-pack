# Access Review Checklist

Date: 2026-05-15  
Use: Simple checklist for running a repeatable access review cycle.

## 1) Review Setup

- [x] Define review scope (systems, departments, user groups)
- [x] Set review period and due dates
- [x] Confirm reviewer and approver roles
- [x] Create evidence folder and file naming standard

## 2) Access Data Collection

- [x] Export current user-to-role/access list
- [x] Pull list of privileged/admin roles
- [x] Pull list of contractors, interns, and temporary accounts
- [x] Confirm source-of-truth user roster for active staff

## 3) Access Validation

- [x] Validate each user access against current job role
- [x] Mark each access decision as Keep, Modify, or Remove
- [x] Document business justification for all privileged access
- [x] Flag stale, duplicate, or excessive permissions

## 4) Exception Handling

- [x] Log all non-compliant access in exception log
- [x] Assign owner and due date for each exception
- [x] Set risk level (High/Medium/Low) for each item
- [x] Track exception status (Open/In Progress/Closed)

## 5) Remediation and Verification

- [x] Create remediation tasks for all Modify/Remove items
- [x] Capture before/after evidence for access changes
- [x] Validate completed changes with reviewer check
- [x] Update table/log/tracker with final status

## 6) Final Documentation

- [x] Publish findings summary and recommendations
- [x] Map outcomes to control references (NIST CSF / HIPAA)
- [x] Confirm all evidence is sanitized
- [x] Confirm audit package is complete and readable
